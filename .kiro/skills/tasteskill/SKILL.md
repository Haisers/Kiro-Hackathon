# TasteSkill

Guidance for producing high-quality, tasteful, consistent user-facing work in this project.

## When to use

- Building or modifying UI components, pages, or layouts.
- Making styling, spacing, color, or typography decisions.
- Reviewing frontend changes for polish and consistency.

## Instructions

1. **Match the existing design language.** Before adding new styles, scan nearby components and reuse existing tokens, utilities, and patterns rather than inventing new ones.
2. **Favor clarity and restraint.** Prefer simple, clean layouts with consistent spacing. Avoid unnecessary visual noise, excessive color, or decoration that doesn't serve the user.
3. **Respect hierarchy.** Use typography, size, and spacing to make the most important content obvious at a glance.
4. **Keep it consistent.** Reuse spacing scales, border radii, and color variables already defined in the project. Don't introduce one-off magic numbers.
5. **Design for all states.** Account for loading, empty, error, hover, focus, and disabled states, not just the happy path.
6. **Accessibility is part of taste.** Ensure sufficient contrast, keyboard navigation, focus states, and meaningful labels/alt text.
7. **Responsive by default.** Verify layouts hold up across small and large viewports.
8. **Explain trade-offs.** When a design decision isn't obvious, briefly note why you chose it.
